## 开头

这里写文章开头。建议用比较自然的方式交代背景，不要一上来就写成论文提纲。

可以使用的 prompt：

```text
请帮我把下面这段内容改写成 Hexo 博客的开头，保持中文、口语化、自然，不要写成公文或论文摘要。开头需要说明这篇文章为什么值得读，但不要夸张营销。
```

## 正文第一部分

这里写第一个主要内容点。每个小节最好只讲一个核心问题，避免把太多内容塞进一个标题下面。

可以使用的 prompt：

```text
请把下面的草稿整理成博客正文小节。要求保留事实、数字、术语和图片位置；优化段落衔接；不要新增没有依据的信息；不要输出“以下是整理结果”这类说明。
```

## 正文第二部分

这里写第二个主要内容点。可以承接上一节继续展开，也可以换一个角度说明。

图片写法示例：

```markdown
![图片说明](https://example.com/image.png)
```

如果图片来自 Word 导入，建议把图片放在相关段落附近，不要全部集中放在文章开头或结尾。

可以使用的 prompt：

```text
请检查下面 Markdown 里的图片位置是否合理。图片应该靠近解释它的段落；如果发现图片被集中放在一起或离上下文太远，请调整到更合适的位置，并保留原有图片链接。
```

## 小结

这里写文章结尾。结尾可以回到文章主题，简单总结读者应该记住的重点。

可以使用的 prompt：

```text
请根据全文写一个自然的博客结尾。要求不要喊口号，不要写得像论文结论，简短总结 2 到 3 个关键点即可。
```

## 发布前检查

- Front Matter 是否完整。
- 标题是否适合直接发布。
- 分类和标签是否准确。
- 图片链接是否能访问。
- 图片是否放在对应上下文附近。
- 代码块语言是否标注正确。
- 是否存在“AI 改写说明”“以下是整理结果”等不该展示给读者的文字。
